Отдельный whitelist.

Например:

# Allowed Futures

## Tier 1

- BTCUSDT
- ETHUSDT
- SOLUSDT

## Tier 2

- ...

## Forbidden

- low-liquidity contracts
- newly listed contracts
- contracts with abnormal spreads
- contracts without sufficient history

Это сильно лучше, чем позволять LLM самостоятельно решать, какие 200 фьючерсов торговать.
