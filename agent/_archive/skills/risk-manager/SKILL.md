Это второй по важности файл после SOUL.

Агент должен сначала рассчитать риск, и только потом решать, можно ли торговать.

Минимально:

Account Equity
Risk per trade
Entry
Stop Loss
Stop distance
Position size
Leverage
Notional value
Fees
Expected slippage
Funding
R:R
Maximum loss

Например:

Account: $1,000

Risk: 0.5%
Maximum loss: $5

Entry: $100,000
SL: $99,500

Stop distance: 0.5%

Position notional:
$1,000

Maximum leverage:
derived from risk rules

Ключевое правило:

Leverage не определяет риск. Position size + stop distance определяют риск.

И обязательно:

Never increase position size merely because higher leverage is available.
