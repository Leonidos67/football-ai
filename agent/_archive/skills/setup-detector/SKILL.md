Это один из самых важных файлов.

Он превращает анализ в формализованный setup.

Например:

SETUP TYPE:
Breakout Retest

DIRECTION:
LONG

ENTRY:
...

STOP:
...

TP1:
...

TP2:
...

INVALIDATION:
...

RISK/REWARD:
...

CONFIRMATIONS:
1.
2.
3.

CONTRADICTING FACTORS:
1.
2.

CONFIDENCE:
...

STATUS:
VALID / INVALID / WAIT

И обязательно несколько типов setup:

TREND_CONTINUATION
BREAKOUT_RETEST
RANGE_REVERSION
LIQUIDITY_SWEEP
MEAN_REVERSION
MOMENTUM
REVERSAL
FAILED_BREAKOUT

Не надо заставлять модель искать только один паттерн.
